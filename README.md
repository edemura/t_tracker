# Трекер задач

Локальное одностраничное приложение без авторизации и серверной базы данных. Первая версия для обсуждения интерфейса и требований.

## Запуск

Нужен установленный Node.js с поддержкой ES-модулей и встроенного `node:test` (например, Node.js 22 или новее). Сторонних зависимостей нет; `npm install` не требуется.

Из папки проекта:

```powershell
npm start
```

Откройте **http://127.0.0.1:8080**. Остановка сервера — `Ctrl+C`. Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd start` либо `node scripts/serve.mjs`.

Используйте этот же адрес при следующих запусках. Другой хост, порт или профиль браузера имеет отдельное хранилище. Двойной щелчок по HTML не подходит: приложение использует JavaScript-модули.

## Возможности первой версии

- Создание, редактирование и удаление задач с подтверждением.
- Название, описание, направление, статус, ответственный и срок.
- Поиск по названию и совместные фильтры по направлению, статусу, ответственному и просрочке.
- Сортировка по сроку, счетчики и выделение просроченных задач цветом и подписью.
- Автоматическое сохранение в браузере после изменений.
- Экспорт и импорт JSON с проверкой формата и подтверждением полной замены данных.
- Адаптивная форма; на узких экранах таблица прокручивается горизонтально.

Первый запуск открывает пустой список. Нажмите «Новая задача». Для смены статуса откройте «Изменить».

## Структура

```text
public/
  index.html            # Разметка страницы и формы
  styles.css            # Стили и адаптация
  js/
    app.js              # Состояние интерфейса и обработчики действий
    tasks.js            # Модель, проверка данных, фильтры и просрочка
    storage.js          # load() / save() для localStorage
scripts/
  serve.mjs             # Локальный статический сервер, только 127.0.0.1
tests/
  tasks.test.js         # Проверки модели и хранилища
docs/
  architecture.md       # Архитектура, формат данных и дальнейшие этапы
package.json            # Команды запуска и тестов
README.md               # Инструкция проекта
```

## Хранение и резервная копия

Все данные находятся в `localStorage` под ключом `taskTracker.data`, в одном JSON-документе версии 1. Сервер только отдает файлы приложения и не получает задачи.

Данные привязаны к браузеру, профилю и адресу. Очистка данных сайта удалит задачи; в приватном режиме хранение временное. Регулярно нажимайте «Экспорт JSON» и храните резервную копию отдельно. «Импорт JSON» **заменяет весь список и справочник направлений**, а не объединяет их. Максимальный размер файла импорта — 5 МБ; доступная квота браузера может быть меньше.

При ошибке загрузки приложение блокирует изменения, не перезаписывая исходную запись. Восстановление — импорт корректной резервной копии. При ошибке записи форма сохраняет введенные значения и показывает сообщение.

Другие вкладки того же браузера получают обновления. Это не полноценный механизм совместного редактирования: одновременную работу нескольких пользователей версия не поддерживает.

## Проверка

```powershell
npm test
```

Ручной сценарий: создать задачу со вчерашним сроком → увидеть просрочку → сменить статус на «Завершена» → убедиться, что метка исчезла → перезагрузить страницу → экспортировать JSON → удалить задачу → импортировать копию и проверить восстановление.

## Следующее обсуждение

После первого запуска согласовать удобство таблицы и формы, набор статусов, необходимость управления направлениями и справочника сотрудников. Авторизация, серверная база, уведомления, вложения и история изменений пока не входят в проект.
